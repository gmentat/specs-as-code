## Example principles (delete when writing project principles)

### 1. Test-first

Every behavior has a test before it has an implementation.
Untested code is unfinished code.

### 2. Simplicity

Prefer the smallest solution that meets the requirement.
Do not build for hypothetical future needs.

### 3. Explicit over implicit

Configuration, dependencies, and data flow are visible in the code.
No magic globals, hidden state, or implicit ordering.
